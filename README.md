# Conductores — mapa de soporte

Página estática de una sola pantalla para ver en el navegador, en pantalla
completa, el mapa en tiempo real de los conductores en línea de Vanko.

Solo entra una cuenta de soporte (teléfono + código OTP); el servidor
(`fn_support_all_vehicle_locations`, Supabase) rechaza a cualquier otra
cuenta. No contiene el código fuente de la app, solo este mapa.
